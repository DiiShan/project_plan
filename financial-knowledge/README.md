## 不要丢掉的研究约束

1. **全量个股财报，本地优先。** 财务数据与经营、行业文本一起入库。见 [终局与定位](BLUEPRINT.md#vision)、[成本与本地优先](BLUEPRINT.md#cost)。
2. **可追溯的事实、关系与变化。** 用真实公告可获得时间和修订版本做历史回放，不用录入时间冒充公告时间。见 [分层架构](ARCHITECTURE.md#architecture)、[数据对象与证据规则](ARCHITECTURE.md#schema)。
3. **动态分组不只要行业标签。** 按共同客户类型、原材料、终端需求和商业模式分组，并保留原料、客户、汇率等暴露；供需和经营机制放在这些分组与传导问题里看。官方行业只是视图之一。见 [要回答的研究问题](BLUEPRINT.md#questions)、[分层架构](ARCHITECTURE.md#architecture)。
4. **假设生成与独立验证分开。** 相关不等于因果；讨论因果要有识别策略并控制混杂。检验包含预注册、多重检验、反例、样本外和纸面前向。见 [持续研究闭环](ARCHITECTURE.md#loop)、[方法如何递进](BLUEPRINT.md#methods)、[验证与风控](BLUEPRINT.md#validation)。
5. **经营事实与股价是否已经反映，分开记账。** 经营预测成立，不等于这一信息仍有交易上的增量价值。见 [要回答的研究问题](BLUEPRINT.md#questions) 第 06 项。
6. **失败保留。** 研究迭代是流程迭代：提出、反证、回放、入库、淘汰。它不是模型自行改训练、奖励、风控或评价口径，也不是自动交易。搜索和假设试验有预算，入库经人审。见 [终局与定位](BLUEPRINT.md#vision)、[研究与交易的边界](BLUEPRINT.md#boundary)。
7. **阶段编号维持 Phase 0 到 Phase 6。** 输入、输出、验收和否决条件见 [分期路线](ROADMAP.md#phases)。
8. **三条示例是纯演示，不是实证发现。** 见 [演示用假设样例](BLUEPRINT.md#examples)。
